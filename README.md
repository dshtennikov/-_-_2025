# Анализ зарплат в Data Science (2021-2024) 2025_Data_00_prepairing_data

Этот репозиторий содержит данные и код для анализа зарплат специалистов в области Data Science за 2021-2024 годы.

## Описание проекта

Проект включает сбор, очистку и анализ данных о зарплатах специалистов в сфере Data Science из различных источников, включая данные о вакансиях с Glassdoor и датасеты о зарплатах.

## Структура проекта

- `2025_Data_00_prepairing_data.ipynb` - основной ноутбук с кодом подготовки данных
- `ds_salaries_2023.csv` - исходные данные о зарплатах за 2023 год
- `glassdoor_jobs_2024.csv` - данные о вакансиях с Glassdoor за 2024 год
- `Glassdoor_Salary_Cleaned_Version_2024.csv` - очищенная версия данных Glassdoor
- `combined_data_jobs_salaries_2023_2024.csv` - объединенный датасет
- `cleaned_data_jobs_salaries_2023_2024.csv` - финальный очищенный датасет

## Основные этапы анализа

### 1. Подготовка данных
- Загрузка данных из нескольких источников
- Объединение таблиц через конкатенацию
- Добавление информации об источнике данных
- Приведение названий колонок к нижнему регистру

### 2. Очистка данных
- Удаление полностью пустых столбцов
- Обработка пропущенных значений
- Преобразование типов данных

### 3. Анализ данных
- Исследование распределения зарплат
- Анализ категориальных переменных
- Построение моделей машинного обучения для прогнозирования зарплат

## Ключевые характеристики данных

- **Временной период**: 2020-2024 годы (преимущественно 2023)
- **География**: Международные данные (США, Канада, Европа, Азия и др.)
- **Отрасль**: Data Science и смежные области (ML, аналитика, инженерия данных)
- **Размер выборки**: 4497 записей (3755 после очистки)
- **Основная валюта анализа**: Доллары США

## Основные столбцы данных

| Столбец | Описание |
|---------|----------|
| `work_year` | Год проведения исследования |
| `remote_ratio` | Процент удаленной работы (0-100%) |
| `company_size` | Размер компании (S/M/L) |
| `experience_level` | Уровень опыта сотрудника |
| `salary_currency` | Валюта зарплаты |
| `company_location` | Страна расположения компании |
| `salary_in_usd` | Зарплата в долларах США |
| `job_title` | Название должности |
| `employment_type` | Тип занятости |
| `employee_residence` | Страна проживания сотрудника |

# Прогнозирование зарплат в сфере Data Science (2023-2024)

## Описание проекта

Этот проект представляет собой анализ и прогнозирование зарплат специалистов в области Data Science и Machine Learning на основе данных за 2023-2024 годы. Проект включает в себя предобработку данных, исследовательский анализ и построение моделей машинного обучения для прогнозирования заработных плат.

## Структура проекта

Проект состоит из трех основных этапов:

### 1. Импорт библиотек и загрузка данных
- Загрузка и первичный анализ датасета
- Исследование структуры данных (40 признаков, 4497 записей)
- Анализ пропущенных значений и типов данных

### 2. Предобработка данных
- Фильтрация данных только за 2023 год
- Выбор релевантных признаков для анализа
- Обработка пропущенных значений
- Очистка данных до 1785 записей

### 3. Анализ влияния факторов на зарплату
- Визуализация влияния уровня опыта, размера компании, должности и удаленной работы
- Статистический анализ корреляций
- Исследование распределения зарплат

## Ключевые особенности

### Анализируемые факторы:
- Уровень опыта (MI, EN, SE, EX)
- Размер компании (S, M, L)
- Должность (топ-10 по зарплате)
- Уровень удаленной работы (%)
- Расположение компании
- Тип занятости

### Технические детали:
- Средняя зарплата: $149,045
- Стандартное отклонение: $61,307
- Диапазон: $7,000 - $423,834

## Используемые технологии

- **Python 3**
- **Библиотеки анализа данных**: pandas, numpy
- **Визуализация**: matplotlib, seaborn
- **Машинное обучение**: scikit-learn
- **Предобработка**: LabelEncoder, StandardScaler, SimpleImputer
- **API Mistral**

## Модели машинного обучения

Проект включает реализацию следующих алгоритмов:
- Линейная регрессия
- Ridge регрессия
- Lasso регрессия
- Случайный лес
- Градиентный бустинг

## Метрики оценки

Для оценки моделей используются:
- Средняя абсолютная ошибка (MAE)
- Среднеквадратичная ошибка (MSE)
- Коэффициент детерминации (R²)
- Кросс-валидация

## Результаты

Проект позволяет:
- Анализировать факторы, влияющие на зарплаты в Data Science
- Строить прогнозы заработных плат на основе характеристик специалиста
- Сравнивать эффективность различных моделей машинного обучения
- Визуализировать распределение зарплат по различным параметрам

## Использование

Для запуска проекта необходимо установить зависимости и выполнить ячейки ноутбука последовательно. Данные должны быть в файле `cleaned_data_jobs_salaries_2023_2024.csv`.
