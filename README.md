# Анализ зарплат в Data Science (2021-2024)

Этот репозиторий содержит данные и код для анализа зарплат специалистов в области Data Science за 2023-2024 годы.

## Описание проекта

Проект включает сбор, очистку и анализ данных о зарплатах специалистов в сфере Data Science из различных источников, включая данные о вакансиях с Glassdoor и датасеты о зарплатах.

## Структура проекта

- `2025_Data_00_prepairing_data.ipynb` - основной ноутбук с кодом подготовки данных
- `ds_salaries_2023.csv` - исходные данные о зарплатах за 2023 год
- `glassdoor_jobs_2024.csv` - данные о вакансиях с Glassdoor за 2024 год
- `Glassdoor_Salary_Cleaned_Version_2024.csv` - очищенная версия данных Glassdoor
- `combined_data_jobs_salaries_2023_2024.csv` - объединенный датасет
- `cleaned_data_jobs_salaries_2023_2024.csv` - финальный очищенный датасет

## Основные этапы анализа

### 1. Подготовка данных
- Загрузка данных из нескольких источников
- Объединение таблиц через конкатенацию
- Добавление информации об источнике данных
- Приведение названий колонок к нижнему регистру

### 2. Очистка данных
- Удаление полностью пустых столбцов
- Обработка пропущенных значений
- Преобразование типов данных

### 3. Анализ данных
- Исследование распределения зарплат
- Анализ категориальных переменных
- Построение моделей машинного обучения для прогнозирования зарплат

## Ключевые характеристики данных

- **Временной период**: 2020-2024 годы (преимущественно 2023)
- **География**: Международные данные (США, Канада, Европа, Азия и др.)
- **Отрасль**: Data Science и смежные области (ML, аналитика, инженерия данных)
- **Размер выборки**: 4497 записей (3755 после очистки)
- **Основная валюта анализа**: Доллары США

## Основные столбцы данных

| Столбец | Описание |
|---------|----------|
| `work_year` | Год проведения исследования |
| `remote_ratio` | Процент удаленной работы (0-100%) |
| `company_size` | Размер компании (S/M/L) |
| `experience_level` | Уровень опыта сотрудника |
| `salary_currency` | Валюта зарплаты |
| `company_location` | Страна расположения компании |
| `salary_in_usd` | Зарплата в долларах США |
| `job_title` | Название должности |
| `employment_type` | Тип занятости |
| `employee_residence` | Страна проживания сотрудника |

## Модели машинного обучения

Для прогнозирования зарплат были использованы:
- **Random Forest Regressor** (MAE: $44,044.80, R²: 0.1914)
- **Linear Regression** (MAE: $45,633.59, R²: 0.1443)

1. Сравнение зарплат по должностям, уровням опыта и странам
